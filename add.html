3 이걸 복사하세요

아래 내용을 통째로 복사한 뒤, GitHub의 items.json 에서 "items": [ 바로 다음 줄에 붙여넣으세요.

이름을 입력하면 여기에 나타납니다.
GitHub에서 items.json 열기 →

4 GitHub에서 할 일

  1. 위 GitHub에서 items.json 열기를 누릅니다.
  2. "items": [ 를 찾습니다. 파일 위쪽에 있습니다.
  3. 그 바로 다음 줄에 복사한 내용을 붙여넣습니다.
  4. 오른쪽 위 Commit changes → Commit changes.
  5. 1~2분 뒤 아카이브와 진학 자료실에 함께 반영됩니다.

+ HTML 파일을 공개 링크로 만들려면

  1. 창고 업로드 화면을 엽니다.
  2. 위쪽 칸(파일 이름 입력란)에 폴더이름/index.html 처럼 영문 폴더 이름을 먼저 치고 / 를 누르면 폴더가 만들어집니다.
  3. HTML 파일을 끌어다 놓고 Commit changes.
  4. 주소는 https://thecozyforest.github.io/dochis-warehouse/폴더이름/ 가 됩니다. 이걸 위 링크 주소 칸에 넣으세요.
이미 있는 폴더 이름은 쓰지 마세요. 기존 자료가 덮어써지고 링크트리에 걸린 주소가 깨집니다.
